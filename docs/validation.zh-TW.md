## 證據涵蓋範圍

這些檢查確認檔案有效性、程式行為、可重現性，以及走路假設下的內部一致性。目前沒有同步光學動作捕捉或其他獨立的關節角真值。較小的傾斜角或較直立的骨架，不等同於解剖姿態準確度。骨盆替代屬於推估，且未提供絕對航向參考、位移重建或腳底接地修正。

## 重新計算的 v1 → v3 比較

以下結果直接由[發布的 v1 與 v3 示範檔](../examples/README.zh-TW.md)重新計算，並非舊有本機 v2 → v3 的比較。v1 檔案只有根節點 X 的 +100 cm 展示平移，不影響這些以旋轉計算的指標。

對於關節全域旋轉 $R_j(t)$，報告中的傾斜角定義為：

$$\theta_j(t)=\cos^{-1}\!\left(\operatorname{clip}(R_{j,yy}(t),-1,1)\right).$$

這是關節座標系的全域 +Y 軸與世界垂直方向之間的夾角，不是相對父關節的角度，也不是相對真值的誤差。解剖對齊、擺動階段及骨骼座標定義都會影響數值，因此數值較低不一定代表較好。

| 關節 | v1：最後 10 秒中位數（°） | v3：最後 10 秒中位數（°） |
| --- | ---: | ---: |
| Hips | 104.94 | 2.65 |
| LeftUpLeg | 19.55 | 19.25 |
| RightUpLeg | 17.61 | 17.14 |
| LeftLeg | 16.46 | 16.42 |
| RightLeg | 143.49 | 17.91 |
| LeftFoot | 87.06 | 17.82 |
| RightFoot | 91.91 | 15.42 |

骨盆、右小腿與足部的明顯變化，與這份紀錄中可見的姿態崩塌及方向漂移受到抑制相符。v1 與 v3 之間包含多項改動，這些數值不能單獨歸因於某一項演算法。[可供程式讀取的摘要](validation/v1-v3.json)也包含前 10 秒的結果。`before`／`after` 是固定的資料集識別鍵值，`labels` 說明所比較的版本。時間由第一個輸出影格起算；第一段使用 `t < 10`，最後一段使用 `t > t_last - 10`。

比較圖另顯示相對胸部的航向：由各關節局部 +X 軸的水平投影計算航向，減去胸部航向後展開角度。其座標軸慣例與校正演算法相同，但繪圖並未在角度展開前套用該演算法的可靠度門檻。軸投影接近垂直時，圖中的航向可能不可靠。

重新計算指令：

```sh
python compare_bvh.py examples/before_v1_x100.bvh examples/after_v3.bvh --before-label "v1 before correction" --after-label "v3 corrected" --output outputs/v1_v3_comparison.png
```

影格數與影格時間必須相符。相同取樣不代表任意兩個檔案涵蓋相同的原始動作區間；BVH 沒有絕對紀錄時間戳。

## 足部濾波使用 0.5 秒的原因

保留在本機的足部融合實驗，以同一組由量測選取的準靜止遮罩比較候選 `tauAcc`，沒有依輸出姿態選取片段。角速度先經局部修復及校正段偏移扣除，再以 200 Hz 的 17 筆取樣視窗計算角速度 RMS、平均加速度及向量標準差。候選片段須符合角速度 RMS 小於 0.6 rad/s、平均加速度模長與校正重力相差小於 0.75 m/s²、加速度向量標準差小於 0.7 m/s²，且校正段後至少連續 10 筆取樣（50 ms）。

一致性指標是平均加速度經初始安裝座標及估計足部旋轉轉換後，與世界垂直方向的夾角，和前述骨骼座標傾斜角不同。既有診斷報告記錄：

| 足部 | offlineVQF `tauAcc=3 s`：差異中位數（°） | offlineVQF `tauAcc=0.5 s`：差異中位數（°） |
| --- | ---: | ---: |
| 左腳 | 42.67 | 11.91 |
| 右腳 | 25.36 | 6.71 |

0.2 秒候選設定進一步降低此差異，但明顯壓縮抬腳動態，因此保留 0.5 秒作為折衷。參考方向使用與融合相同的加速度計，遮罩也不能證明腳底接地，故只能支持內部一致性。這些數值來自保留的參數選擇實驗，不是 v1 → v3 BVH 比較，也不是新的獨立準確度研究。完整實驗報告與腳本保留在本機 `outputs/diagnostics/`，並排除發布。

## 自動化檢查

```sh
python -m unittest discover -v
python validate_bvh.py examples/before_v1_x100.bvh
python validate_bvh.py examples/after_v3.bvh
```

目錄整理後，本機 **39 項測試全部通過**：包含既有 36 項及新增 3 項比較工具回歸測試。測試涵蓋重力／安裝座標轉換、已知航向與偏移、不可交換的 BVH 父子旋轉往返、歐拉角連續性、缺口與固定尾值、成對角速度回捲修復、交叉佐證的骨盆異常及恢復、共同轉彎保留、航向可靠度及恢復，以及比較標籤／取樣／展示平移的不變性。這些是合成與結構測試，不是臨床驗證。

獨立驗證器直接組合各軸旋轉矩陣，不使用 SciPy 的旋轉轉換。兩份示範檔均包含 5,259 個數值有限的影格、66 個通道及 21 個關節；標稱影格率為 60 FPS，首末影格間隔為 87.633333 秒。根位置各軸的變動範圍皆為零。最大骨長變動小於 $3\times10^{-14}$ cm，旋轉正交性殘差小於 $2\times10^{-15}$，符合浮點數捨入誤差量級。

整理目錄後，以保留在本機的原始資料執行完整預設轉換，產生的 BVH 與既有 v3 **逐位元組完全相同**，SHA-256 為 `9d18f032fe36eced0d87cefcd67037027857158377931d3025de560efd86da5f`。這是針對此環境與紀錄的檢查，不保證所有相依套件版本或作業系統都產生完全相同的浮點數文字表示。

GitHub Actions 已設定在 Ubuntu 與 Windows 的 Python 3.10 環境中安裝相依套件、執行測試並驗證兩份示範檔。本機測試成功不代表遠端 CI 已執行；遠端檢查需要先發布儲存庫。

## 閱讀新的轉換報告

轉換器會在 BVH 旁產生 JSON 報告。請搭配動作檢視：

1. 檢查輸入單位、初始校正統計、共同有效區間、截斷原因及輸出影格數。
2. 檢查各感測器的角速度修復數量與估計回捲週期。修復數量很多時應回頭檢查原始訊號，不能視為已成功還原的證明。
3. 檢查融合方法與足部 `tauAcc`；動態加速度下，較快的重力校正存在取捨。
4. 檢查骨盆異常區間、回溯、過渡權重、恢復與被拒絕／不可靠的軀幹參考。替代動作無法還原骨盆的獨立運動。
5. 檢查航向校正幅度與可靠度。長時間無效區間會維持校正量；缺乏可靠校正取樣時，會使用並記錄最初可靠的 2 秒備援；完全沒有可靠觀測的骨段則維持原狀。
6. 比較校正與消融輸出，包含轉彎及後段影格。報告記錄的是演算法決策，並非外部準確度。

確切欄位名稱與調整位置請參閱[參數及報告鍵值](parameters.zh-TW.md)。完整報告可能包含本機路徑及實驗細節，因此保留本機；發布的比較摘要只使用檔案名稱。
