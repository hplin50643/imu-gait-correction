# Comparison screenshots

**English** | [繁體中文](README.zh-TW.md) · [Home](../../README.md)

The four screenshots were supplied by the project owner. Teal shows the corrected v3 reconstruction; gold shows the v1 reconstruction from the original IMU data. The v1 character has a +100 cm X translation for side-by-side display. No screenshot timestamps are inferred.

Each PNG is a lossless center crop to **780 × 580 pixels**, with no resizing, recoloring or regenerated content. [Crop coordinates](crops.json) use the Pillow convention: left/top inclusive, right/bottom exclusive, in source pixels. Original screenshots are backed up locally and excluded from the release.

The screenshots illustrate posture differences, not independently measured pose accuracy. See [validation](../validation.md) for the matching v1→v3 numeric comparison and its limitations.
