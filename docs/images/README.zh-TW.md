# 校正比較截圖

[English](README.md) | **繁體中文** · [首頁](../../README.zh-TW.md)

四張截圖由專案擁有者提供。藍綠色為校正後的 v3 重建，黃色為原始 IMU 資料的 v1 重建。v1 人形為了並排展示，在 X 軸平移 +100 cm；此處不推定截圖時間。

每張 PNG 均以無失真的中心裁切統一為 **780 × 580 像素**，沒有縮放、重新著色或重繪內容。[裁切座標](crops.json)使用 Pillow 定義：包含左／上邊界，不包含右／下邊界，單位為來源圖片像素。原始截圖已在本機備份，不納入發布。

截圖用於呈現姿態差異，不代表已由獨立量測確認姿態準確性。與圖片一致的 v1→v3 數值比較及限制，請參閱[驗證說明](../validation.zh-TW.md)。
